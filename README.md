# 🌿 Touch Grass

**Step away. Step outside.** Touch Grass is a tiny, friendly outdoor-activity app that helps people take a screen break and spend a little time noticing the world around them.

## What it does

- Choose an outdoor break of 5, 10, 15, 30, or 60 minutes.
- Pick gardening, walking, bird watching, plant spotting, or cloud watching.
- Choose **Surprise me!** for a random activity.
- Get a small activity prompt and run a countdown timer with start, pause, resume, and reset controls.
- See a cheerful completion message when your session ends.
- Use the responsive interface on desktop or mobile.

## Run it locally

No dependencies, package manager, API keys, or build step required.

1. Clone or download this repository.
2. Open `index.html` in your browser.

For a local development server, you can optionally run `python3 -m http.server 8000` from the project folder and visit `http://localhost:8000`.
