## Project name
Touch Grass — Step away. Step outside.

## Short description
Touch Grass is a lightweight, beginner-friendly web app that encourages people to take screen breaks and spend time outdoors. Users choose how much time they have, select an activity such as gardening, walking, bird watching, plant spotting, or cloud watching—or choose Surprise Me—and follow a simple countdown timer.

## Problem / motivation
It is easy to spend long stretches on screens without taking a break. Touch Grass makes the alternative feel small and achievable: choose a few minutes, get one simple outdoor prompt, and step away from the screen.

## Proposed solution
A responsive, no-login web app with activity selection, random suggestions, short mission prompts, a timer with pause/resume/reset, and a friendly completion message.

## Tech stack
HTML, CSS, vanilla JavaScript. No dependencies or API keys are required.
