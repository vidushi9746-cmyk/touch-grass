# Contributing to Touch Grass 🌱

Thanks for wanting to contribute! Touch Grass is a small, beginner-friendly open-source project encouraging people to take a break from screens and enjoy the outdoors.

## Getting started

1. Fork the repository and clone your fork.
2. Open `index.html` in a browser. No dependencies are required.
3. Make a focused change in a branch.
4. Test the app at desktop and mobile widths, including keyboard navigation where relevant.
5. Commit your changes and open a pull request with a clear explanation and screenshots for visual changes.

## Contribution ideas

- Add thoughtful outdoor activities and short missions.
- Improve responsive layouts or visual clarity.
- Improve keyboard navigation, focus states, contrast, and screen-reader labels.
- Add a nature bingo mode or a simple session history that stays local to the device.
- Improve documentation and report reproducible bugs.

## Guidelines

- Keep changes small and easy to review.
- Use semantic HTML and accessible labels.
- Keep the project dependency-free unless a change has a strong reason to add a dependency.
- Do not add analytics, accounts, or external services without discussing the change first.
- Be kind and constructive in discussions and reviews.
- Do not claim an issue or pull request is accepted for Hacktoberfest credit; eligibility depends on the event and platform rules.

## Pull request checklist

- [ ] The change solves or clearly describes one problem.
- [ ] I tested the relevant behaviour in a browser.
- [ ] The interface works on a narrow screen.
- [ ] I updated documentation if needed.
- [ ] I included screenshots for meaningful visual changes.

Thanks for helping people spend a little more time outside! 🌿
